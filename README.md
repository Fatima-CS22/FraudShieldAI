# FraudShield AI - Financial Fraud Detection System

Machine Learning based fraud detection system developed using the PaySim financial transaction dataset.

## Features

* Detects fraudulent financial transactions in real time
* Trained and evaluated multiple machine learning models
* Uses LightGBM, XGBoost, Random Forest, Deep Neural Network and Ensemble Learning
* Handles class imbalance using SMOTE
* Provides explainability using SHAP
* Interactive dashboard built with Streamlit

## Technologies Used

* Python
* Scikit-learn
* XGBoost
* LightGBM
* TensorFlow/Keras
* Streamlit
* Pandas
* NumPy
* SHAP
* Plotly

## Project Structure

* app.py : Streamlit application
* best_fraud_model.pkl : Final ensemble model
* lgb_model.pkl : LightGBM model
* scaler.pkl : Feature scaler
* label_encoder.pkl : Label encoder
* train_model.ipynb : Training and experimentation notebook
Note: The final ensemble model file is not included in this repository due to GitHub file size limitations.
